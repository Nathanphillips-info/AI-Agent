# BootDotDev Build an AI Agent Project

In this project I built an Agent that can write, run, and read files in a certain working directory I chose. In certain files it can write python code itself.
I set up rules so that in can only do that in certain files. The purpose of this project was to learn how AI agents work and build my own. I used the Gemini API to build this agent with the free tier. 



Some parts of the code base I had help from the website and steps to guide me in building it. But most of the code is written by hand. It also helped me gain a better understanding of certain modules I can import that will be helpful for writing scripts in the future like OS.

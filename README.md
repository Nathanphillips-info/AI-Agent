# Boot.dev – Build an AI Agent Project

## Overview

In this project, I built a simple AI agent capable of interacting with the local file system. The agent can read, write, and execute files within a controlled working directory, with specific safeguards in place to limit where and how it operates.

The primary goal of this project was to understand how AI agents function under the hood and to gain hands-on experience building one from scratch.

## Features

* Read files from a defined working directory
* Write and modify files with controlled permissions
* Execute Python scripts generated by the agent
* Restrict execution to approved file paths for safety
* Basic rule-based control over agent behavior

## Tech Stack

* Python
* Gemini API (free tier)
* Standard libraries such as `os` for file system interaction

## How It Works

The agent uses the Gemini API to interpret user input and generate actions. Based on predefined rules, it decides whether to read, write, or execute files.

To maintain safety and prevent unintended behavior:

* The agent is restricted to a specific working directory
* File-writing and execution are limited to approved locations
* Rules are implemented to prevent arbitrary system access

## What I Learned

* Core concepts behind AI agents and tool usage
* How to safely allow an AI to interact with a file system
* Structuring Python scripts for modular, controlled execution
* Practical use of modules like `os` for automation and scripting

## Notes

 This project was guided by Boot.dev instructions, though they do not give you answers, they only describe the tasks that need to be completed. This project helped reinforce both Python fundamentals and AI concepts.
